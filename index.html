VOD-engine

A private tool for archiving recorded livestreams and preparing them for YouTube.

VOD-engine is self-hosted software run by a single operator for the livestream VOD channels they manage. It is not a public service: there are no sign-ups, and nobody else's account is ever connected to it.

What it does

  • Picks up new stream recordings from the operator's own storage.
  • Compresses them, trims the intro and outro, and mutes copyrighted music.
  • Fills in the title, description and chapters from the stream's Twitch information.
  • Uploads the result to the operator's YouTube channel as a private video, which the operator reviews and publishes by hand in YouTube Studio.
  • Archives a compressed copy back to the operator's storage.

Google and YouTube access

VOD-engine uses the YouTube API Services to upload videos to the connected channel, read the channel's name, and remove earlier uploads of the same video that it made itself. How that data is handled is described in the privacy policy.
